# 偶尔看群说话

AstrBot 群聊插件：偶尔看群、按动态帧判断要不要接话，并拦截不合适或标记为静默的回复。

## 功能

- 周期看群窗口，每个群独立计时
- 被 @ / 引用 / 叫名字 / 戳一戳时立即进入看群状态
- 短上下文判定：只判断要不要接，返回 `intent`
- 全量上下文生成：由正常 AstrBot 会话链路生成最终回复
- 动态帧间隔，避免每个消息都调用 LLM
- 打分阶段忽略图片和语音，正常回复阶段可使用 AstrBot 的图片转文字
- `<silent>` 等标记拦截，支持概率静默
- 可选审查器；可选独立判定模型

## 安装

把本目录放到 AstrBot 的 `data/plugins/` 下，然后重启 AstrBot。
